# Яндекс Директ: кампании по профессиям

Одна кампания на каждый профиль деятельности из
`packages/validators/src/profession.ts` (кроме «Другое»). Слова в объявлениях
— профессии: психологу «консультации», репетитору «занятия», тренеру
«тренировки». Настройка целей и оплаты за платящих клиентов — в
[`direct.md`](direct.md); тарифы и аргументы — в
[`pricing-strategy.md`](pricing-strategy.md).

Это план для ручного ввода в Директ (или импорта в Коммандер): кампании в
самом Директе не создавались.

## Очерёдность запуска

В продукте платная запись пока длится ровно 60 минут, а сетка — 30
(`docs/beyond-psychologists.md`, шаги 2–3 не сделаны). Бесплатную первую
встречу можно настроить на 30/45/60/90 минут. Поэтому профессии, у которых
«60 минут» не подходит, откладываем.

| Волна | Кампания              | Почему                                                             |
| ----- | --------------------- | ------------------------------------------------------------------ |
| 1     | `search-psychologist` | 60 минут подходят, продукт сделан под них                          |
| 1     | `search-coach`        | то же                                                              |
| 1     | `search-legal`        | то же; «Первичная консультация» настраивается                      |
| 2     | `search-tutor`        | «Пробное занятие» ученик бронирует сам; но у многих занятие 45 мин |
| 2     | `search-trainer`      | «Пробная тренировка» есть; групповые занятия не поддерживаются     |
| 3     | `search-health`       | приём 30–45 мин: ждём «Услуги» и шаг сетки, иначе обещаем лишнее   |

Перед каждой волной — разговор с 3–5 специалистами профиля
(`beyond-psychologists.md`, раздел «Профили деятельности»).

## Общие настройки

| Параметр         | Значение                                                                                                             |

| Тип              | «Конверсии и трафик» (Мастер кампаний), поиск и РСЯ, как у кампании № 715729000: без ключевых фраз и групп           |
| Регион           | Россия (оплата в рублях)                                                                                             |
| Разметка ссылок  | Включить автоматическую (`yclid`) — без неё `paid_month` и `paid_year` не привязать (`direct.md`)                    |
| Счётчик Метрики  | `109190662`; цель кампаний — `paid_month`, остальные цели — `signup_free`, `signup_pro`, `paid_year`                 |
| Стратегия        | «Максимум целевых действий», цена целевого действия «Фиксированная» — 100 ₽ за `paid_month`; недельный бюджет 3000 ₽ |
| Автотаргетинг    | В Мастере кампаний не отключается, только ограничивается по категориям (ниже)                                        |
| Показы           | Весь день, все устройства                                                                                            |
| Мониторинг сайта | Включить                                                                                                             |

**Мастер кампаний и «группы».** В Мастере кампаний нет групп объявлений и
ключевых фраз, поэтому блоки «Группа 1/2/3» ниже — тематические наборы, а не
группы Директа. Заголовки и тексты блока вносим в кампанию как варианты
объявления; «ключевые фразы» блока — ориентир для формулировок и список для
сверки с поисковыми запросами из отчёта (раздел «Проверка и ведение»). Если
позже заведём кампанию с ключевыми фразами («Текстово-графические
объявления»), блоки станут её группами один к одному.

**Автотаргетинг.** Целиком его в Мастере кампаний выключить нельзя, можно
исключить категории запросов: в блоке «Определите аудиторию» переключите
«Аудиторию» на «Настроить вручную», затем в блоке «Минус-слова и исключения»
отметьте категории, по которым показы не нужны. Первые две недели
отмечаем все: «Узкие», «Широкие», «Альтернативные», «Сопутствующие запросы»,
«Запросы с упоминанием вашего бренда» и «…брендов конкурентов». Показы
остаются только по целевым запросам, которые отключить нельзя. Потом
снимаем отметку с «Узких запросов»; остальное оставляем исключённым, пока
отчёт по поисковым запросам не покажет, что это стоит снять.

Каждая кампания ведёт на свою страницу лендинга `/solutions/<slug>`: заголовок,
демо страницы записи, три пункта «как это работает» и первый вопрос FAQ
написаны словами профессии (`apps/web/src/lib/professions.ts`). Ссылка
объявления (`utm_campaign` — профиль кампании):

```text
https://synoro.ru/solutions/<slug>?utm_source=yandex&utm_medium=cpc&utm_campaign=<профиль>&utm_content={ad_id}&utm_term={keyword}
```

| --------------------- | -------------------------- | ---------------------------------- |
| `search-psychologist` | `/solutions/psychologists` | `psychologists`                    |
| `search-coach`        | `/solutions/coaches`       | `coaches`                          |
| `search-legal`        | `/solutions/lawyers`       | `lawyers`                          |
| `search-tutor`        | `/solutions/tutors`        | `tutors`                           |
| `search-trainer`      | `/solutions/trainers`      | `trainers`                         |

Отображаемая ссылка в Директе — подпись после домена (`synoro.ru/…`), она
может отличаться от адреса. Страница `health` обслуживает и врачей, и логопедов, и нутрициологов;
в ней нет обещаний про длительность приёма меньше часа — их добавим вместе с
шагами «Услуги» и «Шаг сетки». Ссылки из списка профессий на главной ведут на
те же страницы, а `/sitemap.xml` перечисляет их все.

Меняя слова профессии, держите их в одном состоянии в трёх местах: словарь
`PROFESSION_TERMS` приложения, `professions.ts` лендинга и объявления
этого документа.

### Что заложено в экономику

Директ списывает деньги только за целевое действие — первую оплату «Про»
за месяц (`paid_month`, 240 ₽): фиксированная цена 100 ₽. После эквайринга
Точки с каждого такого клиента остаётся около 135 ₽, но окупаемость зависит от
того, сколько месяцев клиент остаётся, — этих данных пока нет. Если клиент
затем платит за год, это отдельная конверсия `paid_year`, её в этих кампаниях
не оплачиваем. Через две недели смотрим число `paid_month` и цену одной
оплаты. Долю клиентов, продливших второй месяц, смотрим не раньше чем через
шесть недель (15 дней пробного периода и месяц оплаты) и по ней пересматриваем
цену.

«Фиксированная» цена доступна не для каждой цели: у новых кампаний Директ
не давал выбрать `paid_year` («Эту цель не получится добавить при
фиксированной цене»). Для `paid_month` проверяем при создании; если откажет —
«Средняя за неделю» с той же ценой.

Правила остановки на старте (потом уточняем по данным): вариант объявления
со 100 кликами и без регистраций — убираем; кампания, где цена регистрации
втрое выше целевой после 30 регистраций, — пауза до пересмотра запросов.

ограничения Директа — заголовок 1 до 56 знаков, заголовок 2 до 30, текст до

## Проверка и ведение

Лимиты Директа: заголовок 1 ≤ 56 знаков, заголовок 2 ≤ 30, текст ≤ 81, слово
≤ 22, без «!». Все 36 объявлений выше им соответствуют; меняя тексты, считайте
длину заново.

После запуска каждой волны:

1. Через 7 дней: поисковые запросы каждой кампании → в минус-слова всё,
   что ищет клиента специалиста, а не специалиста.
2. Через 14 дней: число `paid_month` и цена одной оплаты по кампаниям;
   бюджет — в лучшие.
3. Не раньше чем через 6 недель: сколько из них заплатили второй месяц или год —
   по этому решаем, окупаются ли 100 ₽ (`direct.md`, «Окупаемость»).
4. Победивший заголовок переносим в остальные блоки кампании; проигравший
   заменяем новым. Тексты проверяем по `russian-copy`.
