# Аналитика практики («Про»)

Аналог Insights из cal.com под нашу модель. Страница «Аналитика» в кабинете
практики (`/practices/<id>/analytics`) отвечает владельцу на вопросы: сколько
я работаю, сколько клиентов не приходит, откуда деньги, в какие часы я занят.

Только **владелец** и только на **«Про»**: в цифрах деньги и клиенты всей
практики, поэтому администратору страница не показывается. Без «Про»
процедура возвращает `{ pro: false, report: null }`, страница — `ProRequired`.

## Что считается

Окно — последние 30, 90 или 365 дней, заканчивается сейчас. Рядом — то же
число за такое же окно прямо перед ним («Раньше: …»).

| Показатель         | Как считается                                                                                                    |
| ------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Встречи            | записи `consultation` и `free`, статус `active`, без `hold_until`, уже закончились; по `starts_at` в окне        |
| Часов работы       | сумма длительностей этих встреч                                                                                  |
| Онлайн-оплаты      | `payments.status = 'succeeded'`, `paid_at` в окне; **вручную внесённые пакеты сюда не входят** — у них нет суммы |
| Неявки             | `cancel_reason = 'no_show'` / (встречи + знакомства + неявки)                                                    |
| Отмены             | `client` и `staff`; `hold_expired` и `payment_cancelled` — неоплаченные брони, не отмены, их нет                 |
| Клиентов приходило | разные `member_id` с состоявшейся консультацией в окне                                                           |
| Из них новых       | те, у кого **первая в жизни** состоявшаяся консультация попала в окно                                            |
| Блокировки времени | `blocked` не считаются никогда                                                                                   |

Графики — встречи и оплаты по дням (30 дней) или по неделям (90 и 365), с
нулями в пустых днях; день и неделя (с понедельника) — по часовому поясу
практики. «Когда вы работаете» — карта день недели × час начала встречи в том
же поясе.

## Где код

- `packages/api/src/routers/analytics/stats.ts` — запросы (`periodStats`,
  `seriesStats`, `loadStats`); `overview.ts` — процедура `analytics.overview`.
- `packages/validators/src/analytics.ts` — допустимые окна (`ANALYTICS_PERIODS`).
- `apps/app/src/components/booking/practice-analytics.tsx` — страница
  (плитки, графики recharts через `ChartContainer` из `@synoro/ui`).
- Тесты — `analytics.test.ts` рядом (PGlite).

## Что дальше
