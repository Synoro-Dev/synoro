# Не только для психологов: терминология и подходы

Лендинг обещает запись «для всех, кто работает с людьми по записи»
(`apps/web/src/components/landing/audience.tsx`: психологи, коучи,
репетиторы, юристы, тренеры, врачи…), а продукт устроен под одну
профессию. Психологичность зашита не только в словах, но и в правилах:
длительности, отмене, налогах. Этот документ — что поменять и в каком
порядке. Канонические слова — в [`GLOSSARY.md`](../GLOSSARY.md).

## Что сейчас «психологическое»

| Где                                                 | Как сейчас                                                                                                        | Почему мешает другим                                                                                            |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |

Нейтральны уже сейчас и остаются: **практика**, **клиент**, **запись**,
**расписание**, **пакет**, **баланс**, **администратор**.

## Принципы

1. **Код говорит на нейтральном языке.** `Service`, `Booking`, `Credit` —
   никаких `consultation` в именах таблиц, enum и функций.
2. **Интерфейс — словами профиля, а не словами разработчика.** Психолог
   видит «консультации», репетитор — «занятия». Нейтральный запасной
   вариант для «Другое» — «встреча».
3. **Правила — данные практики, а не константы.** Длительность, шаг сетки,
   срок отмены, НДС — настройки с разумными значениями по умолчанию из
   профиля.
4. **Профиль задаёт только значения по умолчанию.** Выбор профиля ничего
   не запрещает; всё можно поменять руками.
5. **Не плодить понятия.** Бесплатная первая встреча — не отдельная
   сущность, а услуга с ценой 0. Пациент, ученик и клиент — один «клиент».

## Профили деятельности

Профиль выбирается при создании практики (вместо плейсхолдера
«Анна Иванова, психолог») и хранится на практике. Словарь — в коде, с тремя
формами множественного числа, без свободного ввода: иначе «1 занятий».

| ------------------------------ | ------------------------------------------ | ------------------- | ----------------------------- | ------ |
| Психолог, психотерапевт        | консультация / консультации / консультаций | Консультация 60 мин | Знакомство 30 мин             | 24 ч   |
| Коуч                           | сессия / сессии / сессий                   | Сессия 60 мин       | Знакомство 30 мин             | 24 ч   |
| Репетитор, преподаватель языка | занятие / занятия / занятий                | Занятие 60 мин      | Пробное занятие 30 мин        | 12 ч   |
| Тренер                         | тренировка / тренировки / тренировок       | Тренировка 60 мин   | Пробная тренировка 60 мин     | 6 ч    |
| Логопед, нутрициолог, врач     | приём / приёма / приёмов                   | Приём 45 мин        | —                             | 24 ч   |

Значения — стартовые, их стоит сверить с 3–5 живыми специалистами каждого
профиля до запуска рекламы на профиль.

## Модель: как поменять

### Услуга вместо `bookingKind`

Новая сущность **Услуга** на практике: название, длительность, цена в
занятиях (0 — бесплатно), кто может записаться (клиент сам / только
администратор, в том числе гостя), активна ли, порядок. `Booking` получает
`serviceId`; `kind` сужается до «запись / закрытое время».

Баланс остаётся **один на практику** в занятиях, а услуга стоит N занятий:
«занятие 60 мин» — 1, «занятие 90 мин» — 2, «пробное» — 0. Пакеты и журнал
баланса не меняются. Запись хранит списанное число занятий, чтобы возврат
при отмене не зависел от того, что цену услуги потом поменяли.

Миграция для существующих практик: создать «Консультацию» (60 мин, 1) и
«Знакомство» (30 мин, 0, только администратор), проставить `serviceId`
существующим записям — поведение не изменится.

### Настройки практики

- **Шаг сетки** 15 / 30 / 60 мин вместо жёстких 30 (CHECK в
  `availability_rules` ослабить до `% 15`). Окна выравниваются по шагу, а
  не по длительности услуги.
- **Перерыв после записи** (0–30 мин): «50 + 10» у психологов, дорога у
  выездных репетиторов. Учитывается при поиске окон; exclusion-constraint
  проверяет сами записи, перерыв — логика окон.
- **Срок отмены** в часах вместо `CLIENT_CANCEL_WINDOW_MS`.

### Деньги и чеки

- **Ставка НДС** — настройка платёжного аккаунта (без НДС / 5 / 7 / 22 %),
  а не `vat_code: 1`; маппинг в коды ЮKassa и Т-Банка — в адаптерах.
- **Самозанятый (НПД)** — отдельный режим: чеки не по 54-ФЗ, а в
  «Мой налог». Нужно проверить, что умеют ЮKassa и Т-Банк для самозанятых,
  прежде чем обещать это на лендинге.
- **Название позиции в чеке** — из пакета и слова профиля («Пакет: 5
  занятий»), а не «консультация».

## Порядок работ

1. **Слова** — сделано. `Practice.profession` (миграция `0005`: старые
   практики — `psychologist`, новые по умолчанию — `other`), словарь
   `PROFESSION_TERMS` / `formatCredits` в
   `packages/validators/src/profession.ts`, выбор профиля при создании
   практики, `TermsProvider` для страниц практики. Чек: «Пакет: 5 занятий —
   {практика}». Длительности пока прежние (60 / 30 мин) для всех профилей;
   столбцы «Услуги» и «Отмена» в таблице профилей — задел для шагов 2–3.
   Не сделано: демо-страницы для других профилей и смена профиля в
   настройках уже созданной практики.
2. **Услуги**: таблица, миграция с бэкфиллом, редактор услуг, выбор услуги
   на странице записи, `computeSlots` по длительности услуги.
3. **Правила**: шаг сетки, перерыв, срок отмены, НДС, НПД.

Шаг 1 даёт основную часть эффекта для маркетинга и делается за пару дней;
шаги 2–3 открывают профессии, где «60 минут ровно в :00» не работает.

## Чего не делаем (пока)

- **Групповые занятия** (вместимость > 1): ломают гарантию «одна запись на
  время» (exclusion constraint) и модель баланса. Позиционирование — работа
  один на один.
- **Несколько специалистов в одной практике**: «Студия» — это несколько
  практик в одном аккаунте. Общий календарь центра — отдельный проект.
- **Свои слова для клиента** («пациент», «ученик»): «клиент» понятен всем,
  а настраиваемые существительные размножат склонения по всему интерфейсу.
- **Баланс в рублях** вместо занятий: для чека нужны «аванс» и последующий
  «зачёт аванса» по каждой записи — сложнее и рискованнее, чем пакеты.
